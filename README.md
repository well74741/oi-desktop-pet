# oi桌宠

一个可爱的桌面宠物程序，支持径向快捷启动、边缘吸附、动画效果等功能。

## 快速开始

### 方式一：双击启动（推荐）
直接双击 `启动桌宠.bat` 文件

### 方式二：命令行启动
```bash
python main.py
```

## 功能特性

- **径向快捷启动**：右键点击桌宠打开径向菜单，最多支持8个快捷方式
- **边缘吸附**：桌宠靠近屏幕边缘时自动吸附，并显示倾斜动画
- **呼吸动画**：自然的呼吸和摆动效果
- **弹性反馈**：点击和菜单交互时有Q弹的缩放动画
- **自定义外观**：支持更换桌宠图片（默认尺寸参照"中"75px，不透明）
- **按下反馈**：点击桌宠时模拟"按下去"动画，松开后过渡回待机呼吸周期
- **全屏检测**：检测到全屏应用时自动隐藏，避免干扰
- **透明PNG支持**：完美显示透明背景图片
- **系统托盘集成**：右键菜单、显示/隐藏控制

## 操作说明

| 操作 | 效果 |
|------|------|
| **左键点击** | 打开/关闭径向快捷菜单 |
| **左键拖拽** | 移动桌宠位置 |
| **松开拖拽** | 靠近边缘时自动吸附并倾斜 |
| **右键点击** | 打开设置菜单 |
| **托盘图标** | 双击显示/隐藏桌宠 |

## 安装依赖

```bash
pip install -r requirements.txt
```

所需依赖：
- PyQt5 >= 5.15
- PyYAML >= 6.0

## 配置说明

### config.yaml - 基础配置
```yaml
pet:
  size: 75               # 桌宠大小（像素）
  opacity: 1.0           # 透明度（0-1）
  image: "assets/oi.png" # 桌宠图片路径

appearance:
  icon: "assets/icon.ico" # 托盘图标
```

### pet_settings.json - 用户设置
此文件会自动生成，存储用户的个性化设置：
- `pet_image`: 自定义桌宠图片路径
- `shortcuts`: 快捷方式库存
- `slot_shortcuts`: 径向菜单中的快捷方式（最多8个）
- `button_size`: 径向菜单按钮大小（默认25）

## 技术实现

### 核心架构
- **GravityPet**：桌宠主窗口，处理显示、动画、交互
- **RadialMenu**：径向快捷菜单，支持动画效果
- **SettingsDialog**：设置对话框，可自定义外观和快捷方式

### 关键技术
- PyQt5 窗口标志：`FramelessWindowHint`, `WindowStaysOnTopHint`, `Tool`
- Qt 属性：`WA_TranslucentBackground`（透明背景）
- QPixmap + QPainter：实现图片缩放、旋转和变形
- 文件图标提取：自动获取exe/lnk文件的图标
- 拖放支持：支持从文件管理器拖拽文件添加快捷方式

### 动画参数
- 呼吸缩放幅度：6%
- 按下目标缩放：0.85（模拟"按下去"）
- 按下过渡时长：0.10s（松开通过弹性动画过渡回待机）
- 边缘吸附阈值：10像素
- 边缘倾斜角度：25度

## 打包成exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --icon=assets/icon.ico ^
  --add-data "config.yaml;." ^
  --add-data "assets;assets" ^
  main.py
```

## 常见问题

**Q: 如何添加快捷方式？**
A: 右键点击桌宠选择"设置"，在快捷方式库存中添加程序或文件夹，然后拖入下方的预览区域。

**Q: 如何更换桌宠图片？**
A: 右键点击桌宠选择"设置"，点击"更换桌宠图片"按钮选择图片。

**Q: 桌宠挡住了全屏应用？**
A: 程序会自动检测全屏应用并隐藏桌宠，全屏结束后会自动显示。

**Q: 快捷方式不显示图标？**
A: 程序会自动提取exe和lnk文件的图标，如果无法提取，可以在设置中手动指定图标图片。
