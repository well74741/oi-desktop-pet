# oi桌宠

一个轻量的 Windows 桌面宠物：**径向快捷启动** + **气泡信息模块** + **AI 助手**。

## 下载

到 [Releases](https://github.com/well74741/oi-desktop-pet/releases/latest) 下载最新的 `oi-pet_Setup_v*.exe`，双击安装即可（Windows）。

## 主要功能

- **径向快捷启动**：左键点桌宠展开一圈按钮，最多 8 个；可以放程序、文件、文件夹、网址或命令，也能把文件直接拖到菜单上添加。
  - **全局热键**：在「设置 → 唤出热键」里点一下、直接按下想用的组合键（如 `Ctrl+Alt+Space`），之后在任何程序里按下就在鼠标位置展开菜单。
  - **已经开着的程序直接切过去**，不再多开一个；按住 `Shift` 点击则强制新开。
- **气泡模块**：桌宠旁边的信息气泡，可以放系统状态（CPU / 内存 / 电池）、天气、番茄钟、计算器、便签、待办、倒计时、计数器、Token 消耗等。「添加模块」里按分组选模板、填一两项就能用，带实时预览；也能自定义（网页接口 / 脚本 / 原始 JSON）。
- **AI 助手**：在气泡里直接对话，能帮你管理待办和提醒、增删气泡模块和快捷按钮、调整桌宠设置，还能在画布 / 拼豆上画画。需要自己填写大模型的 API Key（OpenAI 兼容接口，默认 DeepSeek，也支持本地 Ollama）。
  - 出于安全考虑，AI 默认**不能**创建会执行本地代码或读取本地文件的模块；如需开启，在「设置 → AI 设置」里勾选。
- **聚合AI**：用系统自带的 Edge / Chrome 应用窗口打开各家网页版大模型，左侧贴边栏一键切换站点。
- **无限画布 / 拼豆**：嵌在气泡里的小画板。
- 其他：在线更新（点设置窗右下角的版本号检查，也会自动检查）、边缘吸附、动画、检测到全屏程序时自动隐藏、托盘图标、开机自启。

## 操作

| 操作 | 效果 |
|------|------|
| 左键点击桌宠 | 展开 / 收起径向菜单 |
| 拖动桌宠 | 移动位置，靠近屏幕边缘会吸附 |
| 右键点击桌宠 | 设置 / 气泡开关 / 气泡保持 / 退出 |
| 右键托盘图标 | 设置 / 退出 |

## 数据存放位置

- 安装版：`%LOCALAPPDATA%\oi桌宠\`（设置、聊天记录、各模块数据）
- 从源码运行：项目目录下

设置文件 `pet_settings.json` 里保存着你的 API Key，请勿分享。

## 从源码运行

需要 Python 3.12 或更高版本。

```bash
pip install -r requirements.txt
python main.py
```

## 开发

```bash
python run_all_tests.py     # 运行全部自动化测试
打包.bat                    # 双击即可打包（内部调 build.bat，结束后显示结果）
build.bat                   # 打包：生成便携版 exe 和安装包（输出到 dist/）
```

打包前要准备一个专用的 Python 3.12 环境，并安装 [Inno Setup](https://jrsoftware.org/isinfo.php)（用来生成安装包，没装则只出便携版）：

```bash
py -3.12 -m venv "%LOCALAPPDATA%\oi-packenv"
"%LOCALAPPDATA%\oi-packenv\Scripts\python.exe" -m pip install -r requirements.txt
```

`build.bat` 会先跑全部测试，不通过就拒绝打包。

- `HANDOFF.md`：项目交接文档，记录了架构、每个版本的改动和踩过的坑，接手开发请先读它
- `自定义模块开发指南.md`：如何编写自己的气泡模块
